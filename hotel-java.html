Système de Gestion d'Hôtel

Application de bureau avec interface graphique en Java

← Retour aux projets

À propos du projet

Projet de groupe réalisé dans le cadre de mon cursus à l'UTS : une application de bureau permettant de gérer les réservations, les chambres et les clients d'un hôtel, avec une interface graphique développée en Java.

Expertise Technique

  • Langage : Java
  • Interface : Interface graphique (Swing)
  • Paradigme : Programmation orientée objet

Fonctionnalités clés

  • Gestion des réservations et disponibilité des chambres
  • Enregistrement et suivi des dossiers clients
  • Interface graphique intuitive pour le personnel de l'hôtel
