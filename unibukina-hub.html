À propos du projet

UniBurkina Hub transforme les photocopies, les fichiers épars et les groupes WhatsApp informels en une bibliothèque académique centralisée pour l'Université Thomas SANKARA. Le projet est réalisé dans le cadre de mon mémoire de fin de cycle, avec soutenance prévue en juillet 2026.

Stack Technique

  • Backend : FastAPI (Python 3.11), architecture microservices
  • Base de données : PostgreSQL
  • OCR : PaddleOCR avec détection de layout
  • Recherche : Elasticsearch (recherche plein texte)
  • Frontend : Bootstrap 5
  • Authentification : JWT, streaming temps réel via SSE

Fonctionnalités clés

  • OCR intelligent : conversion des photos de cours, TD et examens en documents numériques éditables
  • Bibliothèque centralisée classée par UFR, filière et module
  • Workflow de validation à plusieurs niveaux (délégué → sous-administrateur → classement officiel)
  • Forum académique modéré
  • Recherche plein texte via Elasticsearch
  • Export multi-formats : PDF, DOCX, XLSX, PPTX, TXT, Markdown

6 microservices opérationnels

  • Auth — Gestion des comptes et de l'authentification
  • GED — Gestion électronique des documents
  • OCR — Extraction de texte et détection de layout
  • Search — Recherche plein texte
  • Forum — Espace de discussion académique
  • Frontend — Interface utilisateur
